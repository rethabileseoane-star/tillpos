# Third-party notices — Background Visual Laboratory

No third-party components are used in this laboratory.

The four background studies use full-bleed approved reference images provided
by TILL, stored in `src/lab/backgrounds/assets/`. These images are the visual
source of truth and are not redistributed.

The following were evaluated during research but are NOT used in the final
light direction:

- `Iridescence` — https://github.com/DavidHDev/react-bits (rejected; CSS
  image composition used instead)
- `Silk` — https://github.com/DavidHDev/react-bits (rejected; CSS image
  composition used instead)
- `HoloMosaic` — https://github.com/DavidHDev/react-bits (rejected; tile grid
  does not suit the light/liquid direction; source removed)

If React Bits code is reintroduced in the future, it is licensed under
**MIT + Commons Clause License Condition v1.0** and must be covered by
this notices file.

The TILL Background Visual Laboratory is an internal design experiment and
must not be extracted and redistributed as a component library.
